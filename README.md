# AI小说创作 Skill（novel-writing）

一个专为长篇连载小说创作设计的 Trae AI Skill，覆盖从大纲规划、章节创作、伏笔管理到风格质检的全流程。

## 特性

- **全流程覆盖**：从大纲规划到每章创作、伏笔管理、质量检验
- **孔二狗式叙事风格**：题材承诺三层 + 四引擎推进（社会/情感/悬疑/爽感）
- **人性化写作规范**：9条基本规范 + 20条负面清单，彻底去AI腔
- **人物气质锚定系统**：每个角色锁定视觉/语言/行为三锚点，防止人设崩塌
- **故事逻辑三铁律**：多米诺原则 + 人设原则 + 不可预测原则
- **伏笔管理**：P1/P2/P3三级优先级 + 回收原则
- **六维度质量检验**：钩子力度/逻辑可回溯/人物活感/语言质地/反转锋利度/余味延展
- **记忆与追踪系统**：追踪文件 + 记忆文件模板，确保长篇上下文不丢失

## 适用场景

- 都市异能、底层逆袭、江湖文学等长篇连载小说创作
- 需要保持人物性格一致性的多角色故事
- 有复杂伏笔需要跨章节管理的长篇小说
- 需要统一风格和语言质感的系列作品

## 安装与使用

### 安装

将 `novel-writing.md` 复制到你的 Trae 项目的 `.trae/skills/` 目录下：

```
your-project/
└── .trae/
    └── skills/
        └── novel-writing.md   ← 放这里
```

### 调用

在 Trae 对话中直接说明需求，例如：

> "帮我规划一部都市异能小说的大纲，主角是底层外卖员，意外获得预知30秒未来的能力"

或：

> "续写第5章，3000字以上"

Skill 会自动加载创作规范、读取上下文、执行风格约束。

### 调用参数

- **书名**：你的小说名称
- **题材/类型**：都市异能、江湖文学、底层逆袭等
- **当前阶段**：大纲规划 / 章节创作 / 修订
- **具体需求**：字数要求、风格调整、人物设定等
